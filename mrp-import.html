1. เข้าสู่ระบบ

กำลังตรวจบัญชี…

กรอกแค่อีเมล แล้วกดลิงก์ที่ส่งไปในเมลเพื่อเข้าสู่ระบบ — ลิงก์ใช้ได้ครั้งเดียวและต้องเปิดในเบราว์เซอร์เดียวกับที่ขอ
ยังไม่มีบัญชี ให้สร้างผู้ใช้ที่ Supabase → Authentication → Users แล้วรัน insert into public.mrp_admins(user_id, note) select id, 'MRP admin' from auth.users where email = '<อีเมล>';
